# Game Development in Ruby

While Ruby isn't the primary choice for AAA 3D titles, it has a passionate community and excellent tools for 2D game development and prototyping.

## Popular Libraries & Engines

*   **[DragonRuby Game Toolkit](https://dragonruby.org/):** A commercial-grade, cross-platform 2D engine built on mruby and C. It powers games on Nintendo Switch, Xbox, PS4, and Mobile.
    *   **Pros:** Hot-reloading, extremely fast (60fps default), zero-dependency deployment.
    *   **Cons:** Paid license (though inexpensive).
*   **[Gosu](https://www.libgosu.org/):** The standard open-source 2D game development library for Ruby. Mature, stable, and hardware-accelerated.
*   **[Ruby2D](http://www.ruby2d.com/):** A simple, declarative 2D graphics library. Great for teaching and simple visualizations.

## Comparative Trends

| Feature | DragonRuby | Gosu | Unity/Godot (Benchmark) |
| :--- | :--- | :--- | :--- |
| **Performance** | High (C-based core). | Good. | Very High. |
| **3D Support** | Limited/Fake 3D. | No. | Full. |
| **Distribution** | One-click build (Console support). | Requires packaging. | Standard industry pipelines. |

## The Indieweb Niche

Ruby shines in the "cozy web" and indie game space where developer happiness and rapid iteration beat raw frame-pushing power.
